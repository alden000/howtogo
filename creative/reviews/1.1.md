## Fixes

### M1 (Medium, privacy honesty): `pv_3e` says "only when a search finds nothing", but the build also calls Claude on 1 result
`src/worker/src/api.ts`: `const FEW = 2;` → `if (results.length < FEW …) aiRewrite(...)`. So with exactly one Layer-1 result the query goes to Anthropic, and the privacy line is not true for that case. (The mistake is in my own §6g.5 copy: §6g.2 says "no results or very few".) Change the copy, not the threshold:

File `src/web/src/i18n/privacy.ts`, key `pv_3e`:
- zh: `**Anthropic 的 Claude：**搜不到时，只收到你要找的字，用来猜是哪个地方。猜的结果最多存 30 天。`
  → `**Anthropic 的 Claude：**几乎搜不到时，只收到你要找的字，用来猜是哪个地方。猜的结果最多存 30 天。`
- en: `**Anthropic's Claude:** only when a search finds nothing, it gets just the words you searched for, to guess the place. We keep its guess up to 30 days.`
  → `**Anthropic's Claude:** only when a search finds almost nothing, it gets just the words you searched for, to guess the place. We keep its guess up to 30 days.`

Counts: en 399 → 400 (≤ 400); zh 593 → 595 Han (≤ 600). The notice stays n = 2 because 1.1 is not released yet. I will update §6g.5 in STYLE-GUIDE to the same text. If the Director would rather keep the old wording, set `FEW = 1` instead. Don't do both.

### L1 (Low, 200 %): the "You said" mic icon sits at the vertical middle of a 2-line row
H2-heard-light-200-zh: the 24 px mic sits mid-row next to the wrapped text and looks lost. Pin it to the first line as `.assistline` does. File `src/web/src/styles/app.css`:
- `.heard{display:flex;align-items:center;` → `.heard{display:flex;align-items:flex-start;`
- `.heard svg.i{width:24px;height:24px;flex:none;color:var(--c-ink-2)}` → `.heard svg.i{width:24px;height:24px;flex:none;color:var(--c-ink-2);margin-top:max(0px,calc((1lh - 24px) / 2))}`

Check that the H2-heard 100 % baselines still look centred. They should, because the row is a single line there.

### L2 (Low, typography): straight quotes in one en string
All other en strings use curly quotes. File `src/web/src/i18n/ui.ts`, key `v_nohear_b` (en):
`Tap \"Try again\", or type instead.` → `Tap “Try again”, or type instead.`
(This is my guide's typo. I'll fix §6g.4 to match.)
