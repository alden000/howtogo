# Creative review — M1 built screens (branch `dev/m1-ui` @ 1501e52)

**Reviewer:** Creative · **Date:** 2026-11-17 · **Mode:** read-only. I looked at 30 of the 36 baselines and rendered my own shots against the dev server (:5500) with real fonts, at DPR 2, in light and dark, at 100/150/200 % and at 1440. I measured computed styles with Playwright.

## Verdict: **APPROVED WITH FIXES** (3 High · 10 Medium · 9 Low)

The build is faithful. Every colour, radius, space, target and motion token in `tokens.css` matches §1–2 exactly. Type roles measure to spec: display 42/900, title 30/700, duration 44/900, tile 29/900, button 23/700, caption 17. The §6b state panel, F1, F2 and F6 read calm and on-voice. No banned words appear in any shipped M1 string. Dark mode is truly dark and keeps AAA contrast. The fixes below are what separates "correct" from award-level. The three Highs must land in the fix round; the Mediums should land there too.

**H2 From-mode title (Director ruling 4), final copy:** **从哪里出发？ / Where are you starting from?** It pairs with 去哪里？/ Where to?, and it is a question, not an instruction. Add a new key `from_title` and use it in `Search.tsx:124` in place of `type_start`. Keep `type_start` (打出发的地方) for the F3 button only.

**"Live" bus-times note (Director ruling 1): NOT hidden yet.** `Routes.tsx:335-340` still renders `note-honest` "巴士时间来自实时信息…" / "Bus times are live…" on every bus option (my H3 shots and the H3 baselines). See finding 2.

## Parity gaps vs the prototype (award-level finish)
- **Motion:** #10 is the gap that matters. The press scale (.97, 160ms), sheet rise (spring 460ms), toast and banner spring, skeleton breathe and seal-dot pulse are all correct.
- **Empty states:** unify on the state panel (#5). H1 with only Home shows one full-width tile and a large empty band. The M4 "Add a place" tile (deferred) will fix this, so keep it on the M4 list.
- **Typography rhythm:** #4 and #15. Note that the baselines use system fallback fonts (deviation 2). With real fonts (Atkinson + Noto SC), the F6 size segment fits 4-up and numerals are tabular, so the 3+1 wrap in the baselines is a test artefact. Consider unstubbing fonts for one 100 % zh baseline per frame.
- **Dark mode:** good. #1 (light seal tile) and #17 are the only blemishes.
- **200 % layout:** no horizontal scroll (scrollWidth 390 = viewport), and targets hold. The weak spots are #3, #6, #7, #8 and #9.
