**Changes to the gate (qa/ only):**
- **Windows paths.** `platform-grep`, `secret-scan`, `size`, `static-pwa` and `playwright.dev.config.mjs` used `new URL(…).pathname`, which gives `/D:/…`, and node resolves that to `D:\D:\…`. They now use `fileURLToPath`, and relative paths compare with `/`. The Platform-folder exclusion in `platform-grep` would otherwise have flagged `platform/` itself. `lighthouse.sh` and `artifact.sh` use `pwd -W`.
- **`artifact.sh`:** Git Bash has no `zip`. The new `scripts/zip.mjs` writes a deterministic zip (sorted entries, fixed mtime).
- **No orphans.** The new `scripts/free-ports.sh` kills the whole process tree listening on the QA ports (4183, 4184, 4186, 18797; IPv4 **and** IPv6). `gate.sh` runs it after every step and on EXIT (`trap`), and `lighthouse.sh` runs it on exit. In this run the IPv4-only first version missed `vite preview` on `[::1]:4186` (one orphan), which QA found and killed after the run, and then fixed. After the fix, 0 listeners remain.
- `lighthouse.sh` no longer exports an empty `CHROME_PATH` on Windows; chrome-launcher finds Chrome itself.
